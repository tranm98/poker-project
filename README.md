🃏 Poker Starting Hand Chart

A little poker project I originally made for my boyfriend, who plays poker.

The idea was pretty simple: make a visual Texas Hold'em starting-hand chart where you can click on a hand and highlight it.

I built the original version while I was learning software development, and I'm coming back to it now to clean it up, fix the things I didn't understand back then, and add some new features.

What it does

- Shows the 169 possible Texas Hold'em starting hands
- Click a hand to highlight it
- Click it again to remove the highlight
- Uses JavaScript to handle the interactions
- Simple HTML/CSS layout

Built With

- HTML
- CSS
- JavaScript

Why I'm Revisiting It

I like coming back to some of my older projects because I can actually see the difference between what I understood then and what I understand now.

When I first made this, I mostly cared about getting it to work. Coming back to it has given me a chance to slow down and ask:

"Why is this working this way?"

That has already led me to find and fix things like JavaScript errors, redundant event handlers, and code that could be cleaned up.

What I'm Learning

While working on this project, I'm practicing:

- Working with the DOM
- JavaScript event listeners
- Adding and removing CSS classes
- Debugging with the browser console
- Cleaning up older code
- Finding redundant code
- Breaking problems down instead of trying to fix everything at once
